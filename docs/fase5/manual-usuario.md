# Manual de usuario de CompraLatino

## Compras

1. Abre el catálogo desde computadora, tableta o teléfono. Busca por texto, filtra y abre la ficha del producto para consultar precio, disponibilidad y modalidad.
2. Usa **Crear cuenta** e inicia sesión. Para realizar un pedido puedes guardar una dirección en el flujo de compra.
3. Para compra directa revisa el producto, la cantidad y el total en USD antes de confirmar. En el ambiente de demostración, el pago se procesa con un token de prueba.
4. Para un producto de subasta crea el pedido e ingresa la oferta en JPY. Si el proveedor está temporalmente indisponible, conserva el código de pedido para consultar el estado y evita duplicar la operación.
5. En **Mis pedidos** consulta el código, estado e historial. En el catálogo revisa las recomendaciones que genera el sistema. Un cliente nuevo puede recibir sugerencias generales hasta acumular historial.
6. Para reportar una incidencia registra el código de pedido, la fecha, la pantalla y el mensaje. Omite contraseñas, datos de pago y tokens.

## Administración

El usuario con rol de administrador abre **Administración**. Allí consulta ventas, pedidos que requieren atención y salud del adaptador, y puede exportar el CSV de transacciones. El **Cuadro de mando ejecutivo** compara periodos de 7, 30 o 90 días. Incluye ventas por pedidos confirmados, porcentaje de compradores recurrentes y entregas. Si el denominador está vacío, muestra «Sin datos». El simulador permite estimar el efecto de una variación porcentual de ventas con los demás factores constantes.

La capacitación se mide en una bitácora del equipo. Registra fecha, participante, funciones demostradas y validación del responsable. La meta propuesta es validar a cinco integrantes antes de la entrega y repetir la inducción cuando cambie el flujo operativo. Cierra la sesión al terminar, especialmente en un equipo compartido.
